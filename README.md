# 📓 Personal Journal App (Python)

A simple **command-line based Personal Journal Application** built using Python.  
This project allows users to **write, view, search, and delete journal entries**, helping beginners learn **file handling in Python**.

---

## 🚀 Features

- ✍️ Add journal entries with automatic date & time
- 📖 View all saved journal entries
- 🔍 Search entries using a keyword
- 🗑️ Delete all journal entries with confirmation
- 📂 Stores data in a text file (`journal.txt`)
- 🛡️ Uses exception handling for safety

---

## 🛠️ Technologies Used

- Python 3
- File Handling
- datetime module

---

## 📁 Project Structure

```
Personal-Journal-App/
│
├── journal.py        # Main Python file
├── journal.txt       # Stores journal entries (auto-created)

```

## ▶️ How to Run

1. Ensure Python 3 is installed:
   ```
   python --version
   ```

2. Run the program:
   ```
   python journal.py
   ```
